# Метод Якоби (Лабораторная работа №1)

Данный пакет содержит реализацию метода Якоби для расчёта собственных векторов и собственных чисел действительной симметричной матрицы.

##  Особенности реализации

* **Универсальность:** Алгоритм корректно работает для любой симметричной матрицы, состоящей из действительных чисел.
* **Безопасность и контракты:** Реализована строгая валидация входных данных. При передаче некорректных данных (пустая, неквадратная или несимметричная матрица) программа останавливается с понятной ошибкой `ValueError`[cite: 1].
* **Защита от зацикливания:** Встроен лимит итераций. Если алгоритм не сходится за отведенное время, выбрасывается `RuntimeError`[cite: 1].
* **Оптимизация:** Угол поворота $\varphi$ всегда выбирается так, чтобы он был меньше $\frac{\pi}{4}$ — это обеспечивает лучшую сходимость метода[cite: 1]. На каждом шаге пересчитываются только изменяемые элементы, без полного перемножения матриц[cite: 1].

## Структура пакета

* `__init__.py` — файл-метка, превращающий директорию в подключаемый Python-пакет[cite: 1].

* `README.md` — документация к проекту.

## Как использовать в своем коде

Функция `jacobi_eigen` принимает на вход матрицу в виде списка списков (`List[List[float]]`) и возвращает кортеж: список собственных чисел и матрицу собственных векторов.

```python
from jacobi_method import jacobi_eigen

# Инициализируем действительную симметричную матрицу
matrix = [
    [4.0, 1.0, -1.0],
    [1.0, 2.0, 1.0],
    [-1.0, 1.0, 2.0]
]

# Запускаем вычисления
eigenvalues, eigenvectors = jacobi_eigen(matrix)

print("Собственные числа:", eigenvalues)
print("Собственные векторы (по столбцам):", eigenvectors)
```
Дополнительные параметры функции:

epsilon (по умолчанию 1e-9) — требуемая точность. Критерием остановки является малость суммы квадратов недиагональных элементов[cite: 1].

max_iterations (по умолчанию 1000) — лимит шагов для предотвращения зацикливания.

 Запуск автоматических тестов
Для проверки корректности алгоритма разработан набор модульных тестов[cite: 1]. Тесты написаны с использованием встроенной библиотеки unittest.

Чтобы запустить проверку, откройте терминал в папке с проектом и выполните команду:

```Bash
python -m unittest jacobi_tests.py
```
